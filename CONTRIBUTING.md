# Contributing

1. Create a virtual environment and install the project with `pip install -e ".[dev]"`.
2. Add or update tests for every behavior change.
3. Run `pytest`.
4. Keep parsing, interpretation, validation, and report rendering separate.
5. Do not add routing assumptions without fixtures demonstrating the relevant X32 scene syntax.

Please include anonymized scene fixtures when reporting parser issues. Check that you have permission to share a scene file before submitting it.
